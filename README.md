# VectorVerse

Real-time crypto, Web3, DeFi, NFT and stock market intelligence.

🔗 Live at [vectorverse.com](https://vectorverse.com)

## Features
- Live price tracking via CoinGecko API
- Real-time crypto and market news aggregation
- Category browsing: Bitcoin, Ethereum, Web3 & DeFi, NFT & Gaming, Stocks, Regulation
- Dark/light theme toggle
- Price alerts

## Stack
- Vanilla HTML/CSS/JS
- Vercel (hosting + serverless API proxy)
- CoinGecko API
